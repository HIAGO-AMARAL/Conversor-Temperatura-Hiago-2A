# Conversor de Temperatura

Programa em Java, de terminal, que converte temperaturas entre **Celsius**, **Fahrenheit** e **Kelvin**.

## Como funciona

1. O programa mostra um menu e você escolhe a unidade de origem.
2. Digita o valor da temperatura.
3. Ele mostra o resultado nas outras duas unidades.
4. O menu repete até você escolher **Sair**.

## Conceitos praticados

- Orientação a objetos (uma classe para cada unidade)
- Menus com `Scanner`, laço `while` e `switch`
- Validação de opções inválidas
- Projeto Maven

## Como rodar

Requer **Java 23** e **Maven**.

```bash
mvn compile exec:java
```
